# Filip Smojver — Software Developer Portfolio

A responsive, high-performance portfolio website built with **Next.js**, **TypeScript**, and **Tailwind CSS**.

Designed to showcase software development projects, technical skills, and professional experience.


## 🛠️ Tech Stack

- **Framework:** Next.js
- **Language:** TypeScript
- **Styling:** Tailwind CSS
 

## 💻 Local Development

```bash
# Install dependencies
npm install

# Run local development server
npm run dev
